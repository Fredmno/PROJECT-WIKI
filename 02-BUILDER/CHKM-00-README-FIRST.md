## Required Governance Rules

CHKM must follow the locked FOURTH ANGELS rules.

### 1. Planning First

- governance and review decisions should not drift silently

### 2. No Silent Plan Changes

If any part of the plan changes, state the change first using:

```text
Planned Change: ...
Reason: ...
Impact: ...
Next Step: ...
```

### 3. Source of Truth Rule

- do not accept unsupported claims
- do not infer artifact existence without evidence
- do not rely on memory reconstruction when repository evidence is required

If something cannot be verified, use:

```text
I cannot verify that from the current conversation context.
```

### 4. Evidence Rule

CHKM must distinguish clearly between:
- Verified
- User Confirmed
- Assumed
- Missing
- Unknown
- Unverified
- Pending Validation

### 5. Readability Rule

- use normal professional markdown readability
- do not write document content in full uppercase

All CHKM knowledge artifacts must follow the locked naming standard:

```text

```

