# HTML DESCRIPTION TEMPLATE

## Purpose

Standardized HTML Description format used during demand evaluation, analysis, qualification, governance review, and business case assessment.

This structure should be used whenever an HTML Description field must be completed or updated.

The objective is to provide a concise, executive-friendly summary while preserving traceability and supporting approval decisions.
